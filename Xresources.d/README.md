Xresources
----------

Contains configuration files and color themes for Xresources.

List of contents
----------------

* `colors/` contains different colorschemes that can be used in Xresources.
* `main.Xresources` is the main file that includes other configuration as needed.
* `rofi-colors` contains different colorschemes for rofi that can be included.
* `rofi.Xresources` holds config for rofi.
* `urxvt.Xresources` holds config for urxvt.
