# sxhkd

Config for [sxhkd](https://github.com/baskerville/sxhkd) — Simple X Hotkey Daemon,
used as the keybinding layer for bspwm.

## Files

| File | Installed as | Notes |
|---|---|---|
| `sxhkdrc` | `~/.config/sxhkd/sxhkdrc` | All hotkey definitions |

## Notes

Linux only. Launched by bspwm on startup — see `config/bspwm/`.

Config dates from ~2017. The sxhkdrc syntax is unchanged on modern versions.

> **Not wired into the setup scripts.**
