# bspwm

Config for the [bspwm](https://github.com/baskerville/bspwm) tiling window manager.

## Files

| File | Installed as | Notes |
|---|---|---|
| `bspwmrc` | `~/.config/bspwm/bspwmrc` | Main config — sets monitors, window rules, and launches sxhkd |

## Notes

Linux only. Keybindings are handled separately by sxhkd — see `config/sxhkd/`.
Colours and terminal appearance are driven by `Xresources.d/`.

Config dates from ~2017 but the bspwmrc format has had no breaking changes.

> **Not wired into the setup scripts.**
