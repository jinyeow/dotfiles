ZSH
---

This is my ZSH config directory. Also known as the `$ZDOTDIR`.

List of contents
----------------

* `config/` contains files for plugin configuration that should be included.
* `custom/` contains custom/modified themes, prompts, colors, plugins, etc.
* `etc/` is the module folder that holds the main core config included in zshrc.
* `sample/` contains some interesting examples/snippets from other zshrcs.
* `utilites/` contains utility functions, scripts that are used for my zshrc.
* `zsh-completions/` contains custom completions I've made for my own scripts
  and/or functions. They also contain completions that I've made for improved
  performance over already existing completions.
