# Commits

Applies when you commit ticketed work inside a git repo. Skip it for a one-off edit with no ticket.

- Finish and commit each ticket task before you start the next one.
- Inside one task, split the work into logical commits, for example one per repo or one per functional area.
- Never bundle two tasks into one commit.
- Each commit follows the conventional-commit rule in [`AGENTS.md`](../AGENTS.md).
