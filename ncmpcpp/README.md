# ncmpcpp

Config for [ncmpcpp](https://github.com/ncmpcpp/ncmpcpp) — a terminal MPD client.

## Files

| File | Notes |
|---|---|
| `config` | Main ncmpcpp config |

## Notes

Linux only. Requires MPD to be running — see `mpd/`.

> **Not wired into the setup scripts.** Install manually by copying
> `config` to `~/.config/ncmpcpp/config` or `~/.ncmpcpp/config`.
