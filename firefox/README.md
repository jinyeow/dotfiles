FIREFOX USERSTYLES CSS
----------------------

`userChrome.css` contains CSS that will change parts of the Firefox UI.

Symlink the `chrome/` directory to `$HOME/.mozilla/firefox/<profile directory>/chrome`.

The `<profile directory>` is usually in the form of *hash.name*:
  * where *hash* is an 8 character string,
  * *name* is usually 'default'
